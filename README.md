# Kas-iQ | Smart AI Financial Assistant 🚀💎

**Kas-iQ** adalah asisten keuangan cerdas berbasis AI yang dirancang untuk membantu pengguna mengelola pengeluaran dan pemasukan dengan pengalaman yang modern, premium, dan intuitif. Dibangun untuk memberikan solusi pelacakan keuangan yang cepat tanpa ribet.

---

## ✨ Fitur Unggulan

- **🧠 Real AI Vision (OCR)**: Cukup upload foto struk belanja (Indomaret, Alfamart, Cafe, dll), dan AI akan otomatis membaca nama toko, rincian item, hingga total belanjaan kamu secara akurat.
- **🎙️ Immersive Voice Assistant**: Catat transaksi hanya dengan suara. Dilengkapi dengan antarmuka visual yang dinamis dan sensor diam (auto-stop) 5 detik untuk kenyamanan maksimal.
- **📊 Bento-Box Dashboard**: Tampilan statistik keuangan yang bersih dan modern terinspirasi dari desain Bento Box, memudahkan pemantauan saldo dan pengeluaran.
- **📱 Full Responsive Design**: Pengalaman premium yang konsisten baik di Desktop maupun Mobile.

---

## 🛠️ Teknologi (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS3, Javascript (ES6+)
- **Build Tool**: Vite
- **AI Brain**: Google Gemini 1.5 Flash (Direct API Integration)
- **Charts**: Chart.js
- **Icons**: Lucide Icons & Custom CSS Animations

---

## 🚀 Cara Menjalankan Project (Local)

1. **Clone Repository**:
   ```bash
   git clone https://github.com/malubullul/kasiq.git
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Run Development Server**:
   ```bash
   npm run dev
   ```
4. **Buka Browser**: Akses ke `http://localhost:5173`
